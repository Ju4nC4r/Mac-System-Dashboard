# mac-system-dashboard

Dashboard local para consultar el estado de este Mac y gestionar procesos bajo demanda.

## Desarrollo

1. Activa el entorno Python: `source .venv/bin/activate`
2. Inicia el servicio: `python backend/app.py`
3. En otra terminal, inicia el dashboard: `cd frontend && npm install && npm run dev`

El panel se abre en el navegador y se conecta solamente con `localhost`.
